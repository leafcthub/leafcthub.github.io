Leaf CT Hub website summary

Leaf CT Hub is a static catalog for leaf X-ray micro-CT datasets, covering both raw and annotated images. Each record shows preview images and links to companion segmentation resources.

What The Website Includes

92 dataset records
13 catalog categories
1147 annotated slices

Catalog

Searchable dataset records with species, common name, imaging equipment, image size, file format, provider credit, and citations when available.

Previews

Lightweight raw-image and grayscale mask previews let visitors inspect representative anatomy and segmentation labels without downloading the full dataset.

Segmentation

Each dataset record lists its annotation classes. Separately, the site also links out to the hosted Leaf CT Segmentation App and related training-pipeline repositories.

Data Access

Browse here, download as it becomes available

Leaf CT Hub stores lightweight metadata and preview images for every dataset record. Full-resolution image stacks and masks are hosted on USDA Ag Data Commons; each record's download link lets you download the data directly from this site.

Reuse Note

Website code is MIT licensed. Dataset images, masks, and annotations remain with their original contributors. Each record shows a citation, along with license and reuse terms from its Ag Data Commons deposit.
