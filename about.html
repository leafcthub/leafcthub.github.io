About

Leaf CT Hub website summary

Leaf CT Hub is a static catalog for plant and leaf X-ray micro-CT datasets, segmentation annotations, preview images, repository links, and companion segmentation resources.

What The Website Includes

92 dataset records
13 catalog categories
1147 annotated slices

Catalog

Searchable dataset records with species, family, common name, imaging equipment, image size, file format, provider credit, source links, and citations when available.

Previews

Lightweight raw-image and grayscale mask previews let users inspect representative anatomy and segmentation labels before opening the source repository.

Segmentation

Dataset records include annotation classes and mask-value summaries. The website also links to the hosted Leaf CT Segmentation App and related source repositories.

Data Access

Browse here, download from trusted repositories

Leaf CT Hub stores lightweight metadata, preview images, and configuration files. Large image stacks and masks remain in DOI-backed or trusted external repositories.

Reuse Note

Website code is MIT licensed. Dataset images, masks, annotations, and source files remain with their contributors or repositories. See each dataset record for attribution, source links, and reuse terms.
