Leaf X-ray micro-CT Datasets

Leaf CT Hub is an open catalog for discovering and reusing plant X-ray micro-CT datasets. The hub provides preview images, segmentation labels, metadata, and repository links to support leaf anatomy, phenotyping, and image segmentation research.

How It Works

Browse here, download from trusted repositories

Leaf CT Hub provides a searchable catalog of dataset records. Large image files and segmentation labels are stored in DOI-backed repositories such as USDA Ag Data Commons, while this website provides metadata, preview images, citations, and direct access links.
